# Payment summary cell audit — solution

Self-contained solution for reconstructing the payment summary of receipt
photos (item-row count, printed totals and their layout-grid cells):

    python3 solution.py <public_dir> <submission_out.csv>

`DESCRIPTION.md` and `payment_summary_solution.ipynb` explain the method and
the cross-validated results.

Development code: https://github.com/Tarun-tech10/payment-summary-cell-audit

The receipt images and the submission file are not included.
